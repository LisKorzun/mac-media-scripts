ТЗ — cut-mp4

Назначение
  Вырезать кусок из уже готового MP4 (без перекодирования).
  Вход — обработанный файл (после to-mp4 и т.п.).
  Выход — mp4 рядом с исходником (stream copy).

Скрипт
  bin/cut-mp4
  bash + ffprobe / ffmpeg
  UI как у to-mp4 (баннеры, цвета, ✓ picked, EN)

Запуск
  cd в папку с mp4 → cut-mp4
  (PATH на bin/ — см. README)

Поиск файла
  Только *.mp4 в текущей папке (игнор *_cut_*).
  Нумерованный список → одна цифра + Enter.
  Показать длительность файла.

Режим вырезки (порядок фиксирован)
  1) Enter start, then end time  (default)
  2) Length from start
  3) Length from end

Ввод времени
  - секунды: 90
  - m:ss: 1:30
  - h:mm:ss: 0:01:30
  Подсказки серым. Повтор при ошибке.
  Кусок внутри длительности файла.

Кодеки / ffmpeg
  Stream copy: -c copy
  -ss / -t после -i (таймлайн сбрасывается в 0 — без «чёрного экрана»)
  -map 0:V -map 0:a? -map 0:s?  (без обложек/data)
  -avoid_negative_ts make_zero -fflags +genpts
  -movflags +faststart
  После успеха: xattr -c
  Copy может чуть сдвинуть стык к ключевому кадру.

Выходной файл
  Рядом с исходником.
  Имя: Исходник_cut_<tag>.mp4
  tag: 010000-010130 | fromstart_0010 | fromend_0030

Подтверждение
  Сводка → y / Y / Enter = да.

Не в этой версии
  Center / encode из оригинала / несколько кусков за раз.
