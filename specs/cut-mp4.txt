ТЗ — cut-mp4

Назначение
  Вырезать кусок из уже готового MP4 (без перекодирования).
  Вход — обработанный файл (после to-mp4 / to-apple и т.п.).
  Выход — mp4 рядом с исходником (stream copy).

Скрипт
  bin/cut-mp4
  bash + ffprobe / ffmpeg / python3
  UI как у to-mp4 (баннеры, цвета, ✓ picked, EN)

Запуск
  cd в папку с mp4 → cut-mp4
  (PATH на bin/ — см. README)

Поиск файла
  Только *.mp4 в текущей папке.
  Файлы `*_cut_*` тоже в списке (пометка already cut) — можно резать дальше.
  Нумерованный список → одна цифра + Enter.
  Показать длительность + число audio / softsubs.

Режим вырезки (порядок фиксирован)
  1) Enter start, then end time  (default)
  2) Keep first … of the file
  3) Keep last … of the file
  4) Drop from start and/or end
     (интро/реклама в начале, титры в конце — типичный кейс)
     Спросить оба значения; 0 / Enter = ничего не отрезать с этой стороны.
     Хотя бы одно > 0; оставшаяся длина > 0.
     Оба отсчёта от исходного файла за один проход.

Ввод времени
  - секунды: 90
  - m:ss: 1:30
  - h:mm:ss: 0:01:30
  Подсказки серым. Повтор при ошибке.
  Кусок внутри длительности файла.

Дорожки (стандарт владельца)
  Типичный вход: video + audio RU/EN + softsubs RU/EN.
  Cut сохраняет все audio (`-map 0:a?`).
  Softsubs: не stream-copy (даёт заморозку хвоста), а rebuild:
    extract SRT (-ss перед -i) → clamp cues к длине клипа → mux mov_text.
  Language/title теги субтитров по возможности сохранить.
  Если softsubs нет — только video+audio.
  Главы: -map_chapters -1.

Кодеки / ffmpeg
  Video/audio: -c copy, -ss / -t ПОСЛЕ -i
    (старт точный; видео может быть чёрным до следующего keyframe; звук ок)
  -map 0:V -map 0:a?  (без обложек/data)
  -avoid_negative_ts make_zero -fflags +genpts
  -movflags +faststart
  После успеха: xattr -c
  Без keyframe-snap старта/конца.

Выходной файл
  Рядом с исходником.
  Имя: Исходник_cut_<tag>.mp4
  tag: 010000-010130 | keepfirst_0010 | keeplast_0030
       | drop_0200_0800 (head_tail; нули опускать: drop_0800_end)

Подтверждение
  Сводка → y / Y / Enter = да.

Не в этой версии
  Center / encode из оригинала / несколько кусков за раз.
