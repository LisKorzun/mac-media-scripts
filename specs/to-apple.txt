ТЗ — to-apple

Назначение
  Интерактивно выбрать один видеофайл в текущей папке запуска
  и сконвертировать под свои Apple-устройства:
  MacBook (основной просмотр), iMac M1, iPhone 14 Pro Max.
  Маленький файл, нормальная картинка, звук и субтитры в штатных плеерах.

Целевая среда
  macOS (zsh/bash, Darwin), тот же стек, что to-mp4 / to-lg-tv.
  Обязательно: Homebrew + ffmpeg (ffprobe, python3; libx265).
  Воспроизведение: QuickTime / TV / Файлы или Фото на iPhone (AirDrop), не USB-телек.

Скрипт
  bin/to-apple
  bash + ffprobe / ffmpeg
  to-mp4 не заменяет и не удаляет: to-mp4 — общий (ширина/CRF вручную, H.264).
  to-apple — фиксированный профиль под эти девайсы.

Запуск
  PATH на bin/, cd в папку с видео, to-apple.
  Выходной mp4 — рядом с исходником.

Поиск файла
  Папка = текущая в Терминале.
  Расширения: mkv, mp4, mov, m4v, avi, webm, ts, m2ts.
  Нумерованный список, UI на английском.
  Выбор: одна цифра + Enter. Один файл за запуск.

Дорожки
  Как to-mp4 / to-lg-tv: цвета, номера через пробел.
  Video: ровно одна.
  Audio: одна или несколько.
  Subtitles: только текстовые вшитые (srt/ass/ssa/webvtt/mov_text) → mov_text в mp4.
  Картинка (PGS/DVD/DVB): нельзя (Apple mp4 не играет image-subs; без burn-in).
  Минимум: >=1 video + >=1 audio.

Настройки (фиксированный профиль, без меню ширины/CRF)
  Контейнер: .mp4 + faststart (iPhone/QuickTime).
  Видео: HEVC libx265, ширина 1920, CRF 22, preset fast, yuv420p, tag hvc1.
    1080p HEVC — MacBook/телефон с запасом; на 24" iMac M1 с дистанции стола нормально,
    4K раздувает файл. Меньше, чем типичный H.264 из to-mp4 при той же картинке.
  HDR (smpte2084 / HLG): tone-map в SDR (одинаково везде, меньше файл).
  Аудио: AAC stereo 160k (DTS/TrueHD на iPhone из файла часто молчат).
  Первая выбранная аудио и первая субтитр — default disposition.

Режим
  1) весь файл (default)
  2) первые N минут — ввести 2, Enter, затем целое N, Enter

Выходной файл
  Рядом с исходником.
  Имя: Исходник_apple.mp4
  Если обрезка: Исходник_apple_firstNm.mp4
  После успеха: xattr -c (как to-mp4).

Подтверждение
  Сводка параметров.
  y / Y / Enter = да; иначе отмена.

Не в этой версии
  Выбор CRF/разрешения (зашито).
  Массовая конвертация сериалов.
  Внешние субтитры, burn-in, PGS, VideoToolbox.
  Профиль под LG (это to-lg-tv).
  Нарезка моментов — из готового `_apple.mp4` скриптом cut-mp4.
