ТЗ — to-lg-tv

Назначение
  Интерактивно выбрать один видеофайл в текущей папке запуска
  и сконвертировать под USB-проигрыватель LG OLED65C24LA (C2, 2022):
  маленький файл, нормальная картинка на 65", звук и субтитры работают.

Целевая среда
  macOS (zsh/bash, Darwin), тот же стек, что to-mp4.
  Обязательно: Homebrew + ffmpeg (ffprobe, python3).
  Выход — флешка / диск → штатный плеер webOS (не Infuse).

Скрипт
  bin/to-lg-tv
  bash + ffprobe / ffmpeg

Запуск
  Как to-mp4: PATH на bin/, cd в папку с видео, to-lg-tv.
  Выходной mkv — рядом с исходником.

Поиск файла
  Папка = текущая в Терминале.
  Расширения: mkv, mp4, mov, m4v, avi, webm, ts, m2ts.
  Нумерованный список, UI на английском.
  Выбор: одна или несколько цифр через пробел (example: 1 3 5). Очередь за один запуск.

Дорожки
  Как to-mp4: цвета video/audio/subtitle, номера через пробел.
  Для каждого выбранного файла — свой выбор дорожек (до старта очереди).
  Со 2-го файла: «Same stream menu numbers as previous? [Y/n]».
  Video: ровно одна.
  Audio: одна или несколько.
  Subtitles: только вшитые; 0 или больше. Без внешних .srt. Без burn-in.
  Минимум: >=1 video + >=1 audio.

Настройки (фиксированный профиль, без меню ширины/CRF)
  Контейнер: Matroska (.mkv) — несколько аудио + soft-subs на C2 стабильнее, чем mp4.
  Видео: HEVC libx265, ширина 1920 (высота чётная, пропорции), CRF 22, preset fast, yuv420p.
    1080p HEVC — компромисс размер/картинка на 65" с дивана; 4K раздувает файл без нужды для USB.
  HDR (smpte2084 / HLG): tone-map в SDR, иначе картинка «серая».
  Аудио: AAC stereo 160k (C2 с USB не играет DTS / TrueHD — отсюда «нет звука»).
  Субтитры текстовые (srt/ass/ssa/webvtt/mov_text): в MKV как SRT.
  Субтитры картинкой (PGS / DVD / DVB): copy, без OCR.
  Первая выбранная аудио и первая субтитр — default disposition.

Режим
  1) весь файл (default)
  2) первые N минут — ввести 2, Enter, затем целое N, Enter
  (проверка на телеке без полной конвертации)
  Режим один на всю очередь.

Очередь
  Общая lib/fixed-profile-queue.sh (bin/to-lg-tv только профиль).
  Сводка → одно подтверждение → последовательный ffmpeg.
  Ошибка на одном файле: лог, остальные продолжают.

Выходной файл
  Рядом с исходником.
  Имя: Исходник_lgc2.mkv
  Если обрезка: Исходник_lgc2_firstNm.mkv

Подтверждение
  Сводка параметров.
  y / Y / Enter = да; иначе отмена.

Не в этой версии
  Выбор CRF/разрешения (зашито под C2).
  Внешние субтитры, burn-in, 5.1 AC3, Dolby Vision.
  Постеры/обложки в USB-галерее webOS (плеер сам берёт кадр).
