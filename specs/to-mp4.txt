ТЗ — to-mp4

Назначение
  Интерактивно выбрать один видеофайл в текущей папке запуска
  и сконвертировать в MP4 под macOS (локальный просмотр).

Целевая среда
  macOS 26.6 (ориентир; Apple silicon / arm64).
  Устройства: iMac, MacBook Air — тот же стек.
  Shell: zsh/bash на Darwin.
  Обязательно: Homebrew + ffmpeg (с ffprobe; обычно и ffplay).
  Желательно: VideoToolbox в сборке ffmpeg (проверка: encoders | grep videotoolbox).
  Опционально: mediainfo (для скрипта не требуется).
  Выход рассчитан на штатное воспроизведение в macOS (QuickTime / TV / плееры с H.264+AAC+mov_text).

Скрипт
  bin/to-mp4
  bash + ffprobe / ffmpeg

Запуск
  Скрипты постоянно лежат в bin/; видео — в любой папке.
  Один раз в ~/.zshrc:
    export PATH="$HOME/DEV/scripts/bin:$PATH"
  source ~/.zshrc  (или новая вкладка Терминала)
  Перейти в папку с видео и вызвать:
    cd ~/DEV/scripts/inprogress
    to-mp4
  inprogress/ — удобная рабочая папка, не обязательна.
  Скрипт ищет видео в текущей папке Терминала (куда сделан cd).
  Выходной mp4 — рядом с исходником.
  Подробнее: README.md, раздел Running scripts.
  Без PATH: ../bin/to-mp4 из папки с видео или cp bin/to-mp4 туда (копию потом удалить).

Поиск файла
  Папка = текущая в Терминале (см. Запуск).
  Расширения: mkv, mp4, mov, m4v, avi, webm.
  Нумерованный список, UI на английском.
  Выбор: одна цифра + Enter. Один файл за запуск.

Дорожки
  Показать все потоки:
    video     — мягкий зелёный
    audio     — мягкий синий
    subtitles — мягкий жёлтый
    остальное — серый
  Выбор номеров через пробел (нумерация с 1 в меню; внутри ffmpeg — реальные index).
  Video: ровно одна.
  Audio: одна или несколько (часто 2, rus/eng).
  Subtitles: только уже вшитые в файл; 0 или больше.
    Без внешних .srt. Без burn-in. В mp4 — soft (mov_text).
  Минимум для старта: >=1 video + >=1 audio.
  UI: английский; заголовки бирюза; выбор фуксия; дорожки целиком мягкими цветами.

Настройки

  Ширина (высота авто, чётная, пропорции):
    1) 320 (180p)
    2) 426 (240p)
    3) 640 (360p)
    4) 854 (480p widescreen) — default
    5) 1280 (720p HD)
    6) 1920 (Full HD / 1080p)
    7) no scale (original)

  Качество CRF (libx264):
    1) 18
    2) 20
    3) 23  (default)
    4) 26
    5) 28

  Режим:
    1) весь файл (default)
    2) первые N минут — ввести 2, Enter, затем целое N, Enter

Кодеки выхода
  Контейнер: .mp4
  Видео: H.264 (libx264) + CRF + scale по ширине
  Аудио: AAC, stereo downmix (-ac 2), ~192 kbps
  Субтитры (если выбраны): mov_text

Выходной файл
  Рядом с исходником.
  Имя вида: Исходник_854_crf23.mp4  (ширина в суффиксе: 854, orig, …)
  Если обрезка: суффикс _firstNm (N — минуты).

Подтверждение
  Сводка параметров.
  y / Y / Enter = да; иначе отмена.

Не в этой версии
  Массовая конвертация сериалов.
  Внешние субтитры, burn-in.
  VideoToolbox вместо CRF.
  Вырез середины / без перекодирования (отдельный скрипт позже).
