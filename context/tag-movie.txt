ТЗ — tag-movie

Назначение
  Переименовать готовый mp4 и записать в него то же название, год, жанр и обложку.
  Пометка категории — Movie, чтобы приложение TV могло открыть файл в «Фильмы».
  Видео и звук не перекодируются.

Скрипт
  bin/tag-movie
  bash + exiftool + python3
  UI как у остальных (баннер, ✓, EN)

Запуск
  cd в папку с mp4 → tag-movie.
  Скрипт читает имя файла и ищет фильм на Кинопоиске.
  На экране три строки: что нашлось, какое будет имя, какой жанр.
  Enter — оставить. n — поправить или выбрать другой фильм из списка.
  Постер 600×900 скачивается сам и кладётся png в ~/Pictures/Video.
  Имя png: «Пила 1.png» или «Паразиты.png». Если такой файл уже есть, он заменяется.
  Если папки Pictures/Video ещё нет, скрипт не останавливается. Постер при скачивании создаёт её. s на обложке пропускает картинку.
  Если нет exiftool или sips — пишет need и имя.
  Поиск: lib/tag-movie.py.

Имя
  Русское [Английское] год
  Слова с Кинопоиска. Хвост после двоеточия отрезается: «Пила: Игра на выживание» → «Пила».
  Английское тоже основное: Saw II → Saw.
  Английского нет, или оно то же, что русское — скобок в имени нет: Брат 1997.
  Убрать предложенное английское: n, потом 0, на строке English title минус. Enter на пустой строке тоже пропускает.
  Цифра сиквела берётся из названия Кинопоиска («Пила 2») или из имени файла (1, 2, I, III).
  Если цифры нет ни там, ни там — в имени её нет. n и номер части, чтобы дописать.
  Пример: Пила 1 [Saw] 2004
  Файл уже назван как «Русское [Английское] год», и русское совпало — английское в скобках не меняется.
  Имя файла без .mp4 и название внутри файла — одна и та же строка.
  В частях имени нельзя / : [ ]
  Слишком длинное имя для файла — попросить другое.
  Уже занятое имя в этой папке или в этой очереди — попросить другое. Чужой файл не затирается.

Жанр
  На карточке список. Enter — оставить предложенное слово.
  Цифра — другое слово из списка. Последний пункт other — своё слово.
  n на этой строке — править имя, не жанр.
  Откуда слово: строка «Жанр» у статьи в Википедии.
  «ужасы» → Фильмы ужасов. «фантастика» → Фантастика. «анимационный» → Мультфильмы.
  Кинопоиск в подсказке жанр не отдаёт. Страницы нет — тот же список, пустой Enter жанр не выдумывает.
  1 Фильмы ужасов — как уже записано у Пилы.
  2 Фантастика — как уже записано у «Назад в будущее».

Обложка
  Берётся у фильма, который оставлен на экране. Отдельный вопрос про постер не задаётся.
  Сайт не ответил или фильма нет — имя руками. s на строке названия пропускает этот файл, остальные продолжаются.
  Обложка не скачалась — png из Pictures/Video или s. Тогда в файл картинка не пишется.
  Жанр не нашёлся — цифра из списка, своё слово в пункте other, или s. Тогда жанр не пишется.
  Старая обложка внутри mp4 заменяется.

Очередь
  Номера файлов через пробел (example: 1 3 5).
  Повтор номера в выборе пропускается.
  На каждый файл одна проверка. Enter = да, n = изменить.
  Сводка всех файлов → одно подтверждение.
  y / Y / yes / Enter = да; n / no = отмена. До подтверждения файлы не меняются.
  После подтверждения: caffeinate -is, пока скрипт жив.
  Ошибка на одном файле: сообщение, остальные продолжаются. В конце exit 1, если были сбои.

Запись
  exiftool, -overwrite_original, без копии _original.
  LargeFileSupport (файлы больше 2 ГБ).
  Название, год, жанр, MediaType=Movie.
  В mp4 обложка — jpeg. png в ~/Pictures/Video остаётся копией.
  Приложение TV берёт jpeg, когда файл добавляют в библиотеку.
  Файл, который уже есть в библиотеке, новую обложку сам не подхватывает.
  После записи скрипт читает теги обратно. Не сошлось — файл не переименовывает.
  Потом mv в той же папке и xattr -c.
  Если имя уже такое — только теги.

Проверка категории
  Скрипт категорию в приложении TV сам не открывает.
  Проверяет владелец: добавить файл, которого в библиотеке ещё не было,
  и посмотреть, попал ли он в «Фильмы».
  Файл, который уже лежит в библиотеке, от новой метки сам не переезжает.

Не в этой версии
  Несколько жанров на один файл.
  Сериалы — bin/tag-show.
