ТЗ — sort-fonts

Назначение
  В корне текущей папки лежат файлы шрифтов с хвостом хеша в имени.
  Одинаковое название с разными начертаниями сложить в одну папку.
  Имя файла: Название-начертание. Начертания нет — только Название.
  Хвост из хеша и длинный хвост из цифр убрать.
  Файлы, которые уже лежат в подпапках, не читать и не двигать.

Скрипт
  bin/sort-fonts
  lib/sort-fonts.py
  bash + python3
  UI как у sort-ready.

Запуск
  cd в папку со шрифтами → sort-fonts.
  Смотрит только корень. Расширения: woff, woff2, ttf, otf, otc, ttc.

Имя
  Срезается конец «.хеш.хеш» (12+ hex) и слипшиеся цифры в конце (8+).
  Подчёркивание между названием и начертанием становится дефисом.
  Начертание — последнее слово, если это Regular, Bold, Italic, Oblique,
  Thin, Light, ExtraLight, SemiBold, Black и такие же составные
  (BoldItalic, BoldOblique, ExtraLightItalic).
  Незнакомое последнее слово тоже начертание, если так называются
  ещё файлы или папка с этим названием уже есть.
  Один файл с незнакомым хвостом целиком: папка SomeFamily-Custom/SomeFamily-Custom.woff2.

Куда
  Каждый файл → папка Название/, даже если он пока один.
  Корень после работы — только ещё не разобранные файлы. Папка — уже разобранное.
  Куда такое имя уже лежит — этот файл пропустить.
  Повторный запуск на уже чистых файлах ничего не двигает.

Подтверждение
  Список переносов и список пропусков.
  y / Y / Enter = да.

Не в этой версии
  Чтение имени из таблиц шрифта.
  Обход подпапок.
  Слияние двух папок одного семейства.
