ТЗ — pack-show

Назначение
  Сериал лежит папками сезонов, внутри эпизоды.
  Собрать все эпизоды в одну новую папку рядом с сериалом.
  Имя: SxxExx · название серии. Если названия серии нет — только SxxExx, без точки.

Скрипт
  bin/pack-show
  bash + python3
  UI как у to-mp4 (баннеры, цвета, ✓, EN).

Запуск
  cd в папку сериала (внутри s01 или Show.S01) → pack-show
  или cd в родителя → выбрать сериал из списка папок, где есть сезоны.

Сезоны
  Папка: s01, Season 2, сезон 3, «2 сезон».
  Или длинное имя, внутри которого есть такая пометка: Desperate.Housewives.S01.
  Номер сезона — число у этой пометки (S, Season, сезон), не год и не 1080.

Эпизоды
  Короткий вид: «NN. название.ext» (пробел после точки необязателен).
  Сезон берётся из папки, номер серии — эти цифры. Название остаётся как в файле.
  Длинный вид: в имени есть S01E12 или 1x12. Сезон и серия — эти цифры.
  Название серии — слова после номера. Точки между ними становятся пробелами.
  Название сериала в начале файла в новое имя не копируется.
  Хвост релиза отбрасывается: 1080p, WEB-DL, AMZN и похожее.
  Названия нет — файл называется S01E12.ext, без средней точки.
  Точка по центру — U+00B7, пробелы вокруг, только когда название есть.
  Расширения: mkv mp4 mov m4v avi webm ts m2ts.
  Имя не подошло — пропуск, файл остаётся.
  Два файла в одно имя — второй не трогать.

Куда
  Новая папка рядом с папкой сериала (для inprogress/Шоу → inprogress/новое имя).
  Имя спрашивается; по умолчанию «<папка сериала> all».
  Перенос (mv), не копия. Пустые папки сезонов не удалять.
  Если файл с таким именем уже есть — пропуск.

Подтверждение
  Полный список «было → стало», затем y / Y / Enter.

Не в этой версии
  Вложенность глубже одного сезона.
  Переименование уже плоской папки.
  Конвертация (это to-apple / to-lg-tv после сборки).
