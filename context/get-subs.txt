ТЗ — get-subs

Назначение
  Со страницы WatchEnglish забрать английские субтитры.
  Сериал — готовые серии одного сезона. Фильм — один файл.
  Положить srt в текущую папку. Видео не скачивать.

Скрипт
  bin/get-subs
  lib/get-subs.py
  python3, без других программ.

Откуда текст
  Сериал. Серия лежит в section.detail-container.detail-episodes.
  Кнопка button.detail-episode.detail-episode--ready — серия, у которой есть видео
  и просмотр ещё не начат. Её data-episode-id совпадает с id в запросе
  /api/core/media/<id>/subtitles?lang=en.
  Скрипт читает тот же список из каталога (video_ready и video_asset_id).
  Фильм. Страница /movies/<имя>. В каталоге type=movie, id фильма — тот же id
  в /api/core/media/<id>/subtitles?lang=en. Готовность: details.video_ready
  и details.video_asset_id.
  Плеер не открывает.

Запуск
  cd в папку, куда класть srt.
  Аргумент — адрес страницы сезона или фильма.
  Сериал без ?season= — сезон 1.
  Дальше номера серий через пробел. Нет номеров — все готовые этого сезона.
  У фильма номера серий нельзя: это ошибка.
  Имя серии: S02E01 · Next.srt. Имя фильма: The Dark Knight.srt.
  Двоеточие в названии становится « - ».
  Повторный запуск заменяет файл с тем же именем.
  Нет сети, нет сезона, серия или фильм не готовы — строка ошибки.
  Файлы этой попытки, которые уже записались, остаются.

Файл srt
  Время из start/end, секунды.
  <br/> — новая строка. Метка font снимается. Пустая реплика не пишется.
