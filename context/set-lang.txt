ТЗ — set-lang

Назначение
  Выбрать, какая звуковая дорожка и какие субтитры включены, когда файл открывается.
  Человек включает остальное в плеере сам.
  Картинка и звук копируются, без перекода.
  Текстовые субтитры пишутся по ходу ролика, рядом с картинкой, а не пачкой в конце.
  Иначе плеер показывает пустую дорожку, даже если её выбрать.

Скрипт
  bin/set-lang
  lib/set-lang.py
  UI как у остальных (баннер, ✓, EN).

Запуск
  cd в папку с уже готовыми роликами → set-lang.
  Список. Номера через пробел, s02 — весь этот сезон из списка, Enter — все ролики папки.
  Дальше два вопроса, предпросмотр, подтверждение.
  y / Y / Enter = да; иначе отмена.

Вопросы
  Звук: 1 English, 2 Russian, Enter оставляет тот, что играет сейчас.
  Субтитры: 1 English, 2 Russian, 3 None.
  Enter на уже готовом файле оставляет субтитры как сейчас.
  Enter на новом файле (конвертация и add-subs) оставляет субтитры выключенными.
  Нет такой дорожки — эта часть не меняется, в терминале есть строка об этом.

Где ещё спрашивает
  add-subs — один раз за запуск, до предпросмотра. Ответ попадает в ту же копию, второй проход по файлу не нужен.
  to-apple, to-lg-tv — один раз перед стартом очереди. После кодирования готовый файл получает этот выбор.
  to-mp4 — один раз перед стартом. После кодирования то же самое.
  Вызов из других скриптов: python3 lib/set-lang.py ask печатает два слова (keep, eng, rus, none).
  python3 lib/set-lang.py apply ФАЙЛ keep none меняет один файл без вопросов.

Файл
  Пишется на место, через временное имя .building.
  Отдельный srt рядом не остаётся.
  Обложка ролика остаётся обложкой.
  mp4 / m4v / mov: текстовая дорожка mov_text. mkv: srt.
