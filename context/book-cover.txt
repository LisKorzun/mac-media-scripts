ТЗ — book-cover

Назначение
  Собрать обложку книги: портрет сверху, белая полоса снизу,
  название большими буквами шрифтом Angelica, 1–3 строки.
  Пропорции как у образцов владельца (портрет на всю ширину, текст слева).

Целевая среда
  macOS, python3, Pillow (уже есть).
  Шрифт Angelica один раз в Font Book или в ~/Library/Fonts
  (файл .otf / .ttf, семейство Angelica). Без шрифта скрипт останавливается.

Скрипт
  bin/book-cover
  lib/book-cover.py

Запуск
  cd в папку книги. book-cover.
  Портрет в этой папке, имя файла portrait.
  Расширения: jpg, jpeg, png, webp, tif, tiff, heic, heif.
  Другие картинки в папке не берутся.

Название
  Из имени папки «Автор - Название [Чтец]», Enter оставляет.
  Буквы становятся большими.
  Без / название остаётся одной строкой. Буквы уменьшаются, чтобы строка влезла.
  Свой перенос: Краткий курс / истории / философии (не больше трёх).
  Перед записью строки показываются. n отменяет.

Картинка
  Холст 1200×1800.
  Портрет заполняет верх (обрезка по центру, лицо лучше в середине кадра).
  Снимок с телефона поворачивается по его ориентации.
  Низ белый. Текст чёрный, слева, по вертикали по центру белой полосы.
  Размер букв как на образце; длинное название уменьшается, чтобы влезло.

Выход
  cover.jpg в этой же папке. Повтор заменяет файл.
  В .m4b и в папку копий её вписывает set-cover.

Не в этой версии
  Другой шрифт вместо Angelica.
  Рамка, подпись автора на обложке.
