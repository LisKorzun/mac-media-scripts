ТЗ — tag-show

Назначение
  Готовые mp4 сериала лежат в одной папке, имена вида «S01E01 · Pilot.mp4».
  Записать в каждый файл сериал, сезон, номер серии, название серии, год, жанр, обложку и описание этой серии.
  Пометка категории — TV Show, чтобы приложение TV могло открыть файл в «Сериалы».
  Имя mp4 становится «S01E01 · Название.mp4»: то же название, что записано внутри. Видео и звук не перекодируются.
  mkv: имя файла становится «S01E01 · Название.mkv». Язык названия — один на папку, русский или английский. Внутрь mkv ничего не пишется.

Скрипт
  bin/tag-show
  bash + exiftool + python3
  Поиск и постер: lib/tag-movie.py
  UI как у tag-movie (баннер, ✓, EN)

Запуск
  mp4: cd в папку с mp4. После sort-ready это папка Apple.
  mkv: cd в папку с mkv. После sort-ready это папка LG.
  В одном выборе либо mp4, либо mkv.
  Список. Номера через пробел, s02 — весь этот сезон из списка, Enter — все ролики папки.
  Название сериала спрашивается один раз на всю папку.
  Если текущая папка называется Apple или LG, подсказка — имя родительской папки.
  Хвост « all» у подсказки снимается: «Отчаянные домохозяйки all» → «Отчаянные домохозяйки».
  Enter — оставить подсказку. Можно напечатать другое имя.
  Кинопоиск ищется один раз. Enter оставляет найденный сериал. n — другое имя. Цифра — другой из списка.
  mp4, не нашлось или нет сети: Enter — год, жанр и обложка руками. s — файлы не менять.
  mkv, не нашлось или нет сети: другое имя или s. Год руками не спрашивается.
  Жанр — один на весь сериал, список как у tag-movie. Enter оставляет слово из Википедии. Нет слова — цифра из списка или s, тогда жанр не пишется.
  Обложка не скачалась — png из ~/Pictures/Video или s, тогда картинка не пишется.
  Постер сериала 600×900 скачивается сам и кладётся png в ~/Pictures/Video.
  Имя png — название сериала. Если такой файл уже есть, он заменяется.
  Если папки Pictures/Video ещё нет, скрипт не останавливается. Постер при скачивании создаёт её. s на обложке пропускает картинку.
  Для mp4 названия и описания серий: Enter ищет, s пропускает. Нет текста — поле остаётся пустым, название берётся из имени файла.
  Для mkv названия ищутся всегда. Отдельный вопрос про поиск не задаётся.
  Для mp4, если нет exiftool или sips — пишет need и имя. Для mkv они не нужны.

Что пишется в файл
  Сериал — подтверждённое русское имя.
  Сезон и номер серии — из «S01E01» в имени файла.
  Название серии в файле — русское и английское с 2sub.movie: «Тайны Вистерия Лейн [Pilot]».
  Если этой серии на 2sub нет — пара с Кинопоиска. Если пары нет, в файл пишется текст после точки «·», а если его нет — «S01E01».
  Имя mp4 — как у mkv: «S01E01 · Название». Язык один на всю папку. 1 или Enter — русский. 2 — английский.
  Нет названия на выбранном языке — в имени остаётся только номер.
  Имя уже такое — файл не переименовывается.
  Такое имя уже занято другим файлом — этот файл не переименовывается.
  Год — начало выхода сериала, одно на все серии.
  Жанр — один пункт из списка.
  Обложка — один постер сериала внутри каждого выбранного файла.
  Кадр конкретной серии не ищется.
  Описание — своё у каждой серии. Сначала 2sub.movie.
  Если там текста этой серии нет — страница этой серии на Кинопоиске.
  Если и там нет — страница «содержание серий» на Кино-Театр.Ру.
  Общее описание сериала в файлы не пишется. Нет текста этой серии — поле остаётся пустым.

Пропуск
  Имя не вида «S01E01» или «S01E01 · название» — файл остаётся, в конце сказано сколько таких.

Запись
  exiftool, -overwrite_original, без копии _original.
  LargeFileSupport.
  Title, TVShow, TVSeason, TVEpisode, год, жанр, MediaType=TV Show.
  LongDescription и Description — только если у этой серии нашёлся свой текст.
  В mp4 обложка — jpeg. png в ~/Pictures/Video остаётся копией.
  После записи скрипт читает теги обратно. Не сошлось — этот файл считается ошибкой, остальные продолжаются.
  Потом xattr -c. Затем имя mp4 получает название серии, если оно нашлось.
  y / Y / yes / Enter = да; n / no = отмена. До подтверждения файлы не меняются.
  После подтверждения: caffeinate -is, пока скрипт жив.

Проверка категории
  Скрипт категорию в приложении TV сам не открывает.
  Проверяет владелец: добавить файл, которого в библиотеке ещё не было,
  и посмотреть, попал ли он в «Сериалы».
  Файл, который уже лежит в библиотеке, от новой метки сам не переезжает.

MKV
  Та же команда. Список показывает mkv. Номера через пробел.
  Название сериала — как у mp4, один раз. Подсказка из папки: если текущая называется LG, берётся имя родительской.
  Нет сети или сериал не нашёлся: другое имя или s. Год, жанр и обложка не спрашиваются. Файлы не меняются.
  Язык названия — один на всю папку. 1 или Enter — русский. 2 — английский.
  Название серии: 2sub.movie, если этой серии там нет — Кинопоиск. Описание не ищется.
  Имя файла: S01E01 · Название.mkv. Точка по центру — U+00B7, пробелы вокруг.
  Знаки, которые нельзя положить на флешку (: * ? " < > | / \), становятся пробелами.
  Нет названия на выбранном языке — этот файл остаётся со своим именем.
  Имя уже такое — файл не переименовывается.
  Такое имя уже занято другим файлом — этот файл не переименовывается.
  Внутрь файла ничего не пишется. Видео не перекодируется.
  До подтверждения файлы не переименовываются.
  y / Y / yes / Enter = да; n / no = отмена.

Не в этой версии
  Своя картинка на каждую серию.
  Несколько жанров.
  Подпись, жанр и обложка внутри mkv.
