ТЗ — tag-show

Назначение
  Готовые mp4 сериала лежат в одной папке, имена вида «S01E01 · Pilot.mp4».
  Записать в каждый файл сериал, сезон, номер серии, название серии, год, жанр, обложку и описание этой серии.
  Пометка категории — TV Show, чтобы приложение TV могло открыть файл в «Сериалы».
  Имя файла не меняется. Видео и звук не перекодируются.

Скрипт
  bin/tag-show
  bash + exiftool + python3
  Поиск и постер: lib/tag-movie.py
  UI как у tag-movie (баннер, ✓, EN)

Запуск
  cd в папку с mp4. После sort-ready это папка Apple.
  Список, номера через пробел.
  Название сериала спрашивается один раз на всю папку.
  Если текущая папка называется Apple или LG, подсказка — имя родительской папки.
  Хвост « all» у подсказки снимается: «Отчаянные домохозяйки all» → «Отчаянные домохозяйки».
  Enter — оставить подсказку. Можно напечатать другое имя.
  Кинопоиск ищется один раз. Enter оставляет найденный сериал. n — другое имя. Цифра — другой из списка.
  Не нашлось или нет сети: Enter — год, жанр и обложка руками. s — файлы не менять.
  Жанр — один на весь сериал, список как у tag-movie. Enter оставляет слово из Википедии. Нет слова — цифра из списка или s, тогда жанр не пишется.
  Обложка не скачалась — png из ~/Pictures/Video или s, тогда картинка не пишется.
  Постер сериала 600×900 скачивается сам и кладётся png в ~/Pictures/Video.
  Имя png — название сериала. Если такой файл уже есть, он заменяется.
  Если папки Pictures/Video ещё нет, скрипт не останавливается. Постер при скачивании создаёт её. s на обложке пропускает картинку.
  Названия и описания серий: Enter ищет, s пропускает. Нет текста — поле остаётся пустым, название берётся из имени файла.
  Если нет exiftool или sips — пишет need и имя.

Что пишется в файл
  Сериал — подтверждённое русское имя.
  Сезон и номер серии — из «S01E01» в имени файла.
  Название серии в файле — русское и английское с Кинопоиска: «Пилот [Pilot]».
  Имя файла не меняется. Если пары названий нет, в файл пишется текст после точки «·», а если его нет — «S01E01».
  Год — начало выхода сериала, одно на все серии.
  Жанр — один пункт из списка.
  Обложка — один постер сериала внутри каждого выбранного файла.
  Кадр конкретной серии не ищется.
  Описание — своё у каждой серии. Сначала страница этой серии на Кинопоиске.
  Если там текста нет — страница «содержание серий» на Кино-Театр.Ру.
  Общее описание сериала в файлы не пишется. Нет текста этой серии — поле остаётся пустым.

Пропуск
  Имя не вида «S01E01» или «S01E01 · название» — файл остаётся, в конце сказано сколько таких.

Запись
  exiftool, -overwrite_original, без копии _original.
  LargeFileSupport.
  Title, TVShow, TVSeason, TVEpisode, год, жанр, MediaType=TV Show.
  LongDescription и Description — только если у этой серии нашёлся свой текст.
  В mp4 обложка — jpeg. png в ~/Pictures/Video остаётся копией.
  После записи скрипт читает теги обратно. Не сошлось — этот файл считается ошибкой, остальные продолжаются.
  Потом xattr -c. Переименования нет.
  y / Y / yes / Enter = да; n / no = отмена. До подтверждения файлы не меняются.
  После подтверждения: caffeinate -is, пока скрипт жив.

Проверка категории
  Скрипт категорию в приложении TV сам не открывает.
  Проверяет владелец: добавить файл, которого в библиотеке ещё не было,
  и посмотреть, попал ли он в «Сериалы».
  Файл, который уже лежит в библиотеке, от новой метки сам не переезжает.

Не в этой версии
  Своя картинка на каждую серию.
  Переименование файла.
  Несколько жанров.
