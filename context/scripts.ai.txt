## Зачем
Bash-скрипты для медиа на macOS. Сюда только инструменты; готовые файлы — в библиотеки владельца.

Приоритет: **видео фильмов** (контейнер + дорожки, звук внутри файла). Аудиокнига — отдельно: `to-m4b` / `to-mp3`, не путать со звуком внутри видео.

## Раскладка
| Путь          | Зачем                                              |
| ------------- | -------------------------------------------------- |
| `bin/`        | запускаемые скрипты (kebab-case: `to-mp4`, …)      |
| `lib/`        | общий код: `fixed-profile-queue.sh`, `fix-subs.py`, `to-txt.py`, `tag-movie.py`, `get-subs.py`, `add-subs.py`, `set-lang.py`, `book-audio.sh`, `book-audio.py`, `join-mp3.py`, `name-mp3.py`, `book-cover.py`, `set-cover.py`, `set-narrator.py`, `set-genre.py`, `sort-fonts.py`, `to-ttf.py` |
| `inprogress/` | временные медиа; после работы очищать              |
| `context/`    | `scripts.ai.txt` и ТЗ `context/<script>.txt`       |
| корень        | `README.md`, `.gitignore`                          |

Флоу: скрипты в `bin/` (не копировать в репо медиа). Видео — где угодно; часто `inprogress/`.
Запуск: PATH на `~/DEV/scripts/bin` в `~/.zshrc` → `cd` в папку с видео → `to-mp4` / `to-apple` / `to-lg-tv` / `cut-mp4` / `tag-movie` / `tag-show` / `add-subs` / `set-lang`. Аудиокнига: `cd` в папку глав → `join-mp3` / `name-mp3` / `book-cover` / `to-m4b` / `to-mp3` / `set-cover`. `name-mp3` меняет один файл и его название внутри. Чтеца у уже собранной книги пишет `set-narrator` в папке с файлом `.m4b` (см. [[README.md]]). Жанр туда же пишет `set-genre`: номер из списка, Enter оставляет уже записанный. Литература — роман или рассказы. Философия — статья или трактат. Сборник с разными чтецами: одно слово, Enter — «Сборник», иначе Книги пишут «Неизвестный автор». У каждого mp3 свой чтец.
`to-apple` / `to-lg-tv` / `to-m4b` / `to-mp3` после подтверждения сами делают `caffeinate -is` (ночь без отдельной команды).
Скрипт смотрит только **текущую папку Терминала**; выход рядом с исходником → готовое в библиотеку → `inprogress/` очистить при необходимости.
`to-mp4` — общий конверт (mkv/… → mp4, ширина/CRF руками, H.264). `to-apple` — фикс-профиль под MacBook / iMac M1 / iPhone 14 Pro Max: mp4 + HEVC 1080p + AAC + mov_text. `to-lg-tv` — USB LG OLED65C24LA (C2): mkv + HEVC 1080p + AAC + SRT. `cut-mp4` — вырезка из **уже готового** mp4 (stream copy). `pack-show` — сезоны `s01` или `Show.S01`, серии `01. Название` или `Show.S01E01.Title…` → одна папка `S01E01 · Название.ext` (без названия серии — `S01E01.ext`; mv, предпросмотр). `sort-ready` — если есть и `_apple`, и `_lgc2`: в `Apple/` и `LG/` без суффикса, оригинал удалить; один конверт — не трогать. `clean-stick` — только на томе `/Volumes/…`: удалить `._*` и `.DS_Store`, затем повторная проверка.
`fix-subs` — готовый mp4/mkv: буквы-двойники по пометке rus/eng; английская реплика из больших букв становится обычным предложением. Видео и звук copy. То же вызывает очередь после успешного encode. `to-txt` — Word/DjVu → txt и docx для Pages; при запуске выбор меток сносок (stars/numbers/none), в файл пишутся номера; скан PDF не берёт. `tag-movie` — папка только с mp4 или только с mkv. mp4: по имени файла Кинопоиск предлагает русское и английское (`Пила 1 [Saw] 2004`), жанр подставляется из Википедии в тот же список, Enter оставляет. mkv только переименовывается в `Название · год` (пример `Пила 1 · 2004`); внутрь файла ничего не пишется. Постер 600×900: png в `~/Pictures/Video`, в mp4 — jpeg, MediaType Movie. Нет сети: имя руками, s пропускает этот файл, обложку или жанр. `tag-show` — mp4 сериала `S01E01 · Название`: имя сериала спрашивается (подсказка из папки), список: номера, s02 на сезон, Enter на все файлы; сезон и серия из имени файла; имя mp4 становится `S01E01 · Название` на одном языке, как у mkv (Enter — русский, 2 — английский); год, жанр и один постер сериала пишутся в каждый файл, MediaType TV Show; название серии в теге Title — русское и английское с 2sub.movie (`Тайны Вистерия Лейн [Pilot]`), если этой серии там нет — с Кинопоиска; описание каждой серии сначала берётся с 2sub.movie, если текста этой серии там нет — со страницы серии на Кинопоиске, затем со страницы содержания на Кино-Театр.Ру; общее описание сериала не пишется. Нет сети: Enter вводит год руками, s не меняет файлы; обложку, жанр и описания серий можно пропустить той же буквой. Приложение TV подхватывает обложку при добавлении файла в библиотеку. exiftool, без перекода. Категорию в приложении TV владелец проверяет сам на файле, которого в библиотеке ещё не было. mkv (папка LG): только переименование в `S01E01 · Название.mkv`, язык один на папку (Enter — русский, 2 — английский). Название с 2sub.movie, если этой серии там нет — с Кинопоиска. Нет названия на выбранном языке или имя уже занято — файл остаётся. Жанр, обложка и подпись внутрь mkv не пишутся. В одном выборе только mp4 или только mkv. exiftool для mkv не нужен. `tailwind-clr` — палитра Tailwind → `inprogress/tailwind.clr` (проверить → перенести); `--install` в `~/Library/Colors`. `get-subs` — WatchEnglish: английские srt в текущую папку. Сезон сериала — готовые серии (`video_ready`), файл `S02E01 · Название.srt`; номера серий аргументами, без них весь сезон из ссылки. Фильм `/movies/<slug>` — один файл `The Dark Knight.srt`, если `details.video_ready`. Запрос тот же: `/api/core/media/<id>/subtitles?lang=en`. Плеер и видео не открывает. `add-subs` — внешний srt/json на копию ролика, исходник не меняется. Режим 1: время как в файле, сдвиг Enter = 0. Режим 2: ролик 25/1, время × 23,976/25, сдвиг Enter = 0,6 (второй сезон «Отчаянных домохозяек»), на паузе строка ещё до 0,8 с. Копия: Enter — `Имя.eng.ext` рядом; имя папки — `папка/Имя.ext` без пометки .eng/.rus. Субтитры только внутри ролика, отдельный srt рядом с копией не пишется. Выбор: номера, `s02` на сезон, Enter на все ролики папки. Повтор заменяет копию. В списке нет уже готовых `.eng`/`.rus`, `_apple`, `_lgc2`. Перед записью те же вопросы, что у `set-lang`. Новая дорожка сама не включается. `set-lang` — у уже готового файла выбрать, какой звук и какие субтитры включены при открытии (eng/rus, у субтитров ещё none). Enter у звука не меняет его. Enter у субтитров на готовом файле не меняет их, на новом файле оставляет выключенными. Текстовые субтитры пишутся по ходу ролика, не пачкой в конце. Тот же вопрос задают `add-subs`, `to-apple`, `to-lg-tv`, `to-mp4`. `to-m4b` — все главы текущей папки в один M4B: AAC стерео 96 кбит/с. Имя файла `Автор · Название [Чтец] · год`. В Книгах название `Автор · Название · год`, поле автора — автор книги, исполнитель и диктор — чтец, артист тоже чтец (группировка), тип «аудиокнига». Год написания ищется в ru.wikipedia, иначе вопрос. Строка содержания: `01. Название · год`. «Часть», «Глава», «Фрагмент» заменяют название и тогда без года: `01. Глава 2`. Цифры `02-01` ищутся в начале, середине и конце имени и спрашиваются (пример: Глава, Фрагмент). Чужие буквы тега не пишутся, после записи строка сверяется. `to-mp3` — копии в папку с тем же именем, что файл .m4b; звук mp3 не пережимается; имя файла `01. Название · год.mp3`, а если есть часть или глава — `01. Название · Часть 1. Глава 1.mp3`. Альбом — `Автор · Название · год`, поле автора — полное имя, исполнитель и артист — чтец «Фамилия Имя»; если чтецы разные, артист файла — его чтец, альбомный артист — автор, в m4b артист пустой, название дорожки совпадает со строкой содержания. `pack-books` запускается в папке автора и собирает выбранные книги: папка «Название [Чтец]», m4b, копии, обложка. Исходные главы после сборки можно перенести в «· исходники». Исходники до сборки не меняются. `join-mp3` — соседние mp3 одного рассказа в один файл без перекода; куски удаляются, номера после них уменьшаются. Имя: Enter оставляет предложенное. `book-cover` — файл `portrait.jpg` (png/webp/tif/heic тоже) в папке книги → `cover.jpg`: портрет сверху, название шрифтом Angelica слева внизу, 1–3 строки; свой перенос через `/`. Шрифт один раз в Font Book. `set-cover` вписывает `cover.jpg` в `.m4b` и в папку копий с тем же именем без перекода; повтор заменяет картинку; исходные главы не трогает. Книги подхватывают обложку при добавлении файла. `set-narrator` вписывает одного чтеца в уже собранную книгу без перекода: папка «Название [Чтец]», файл и папка mp3 «Автор · Название [Чтец] · год», в полях «Фамилия Имя»; имена глав не меняются. `sort-fonts` — woff/woff2/ttf/otf в корне текущей папки: каждый файл в `Family/Family-Style.ext`, даже один; хвост хеша убирается; начертание без дефиса (`NameBold`) отрезается; имя с большой буквы, `%20` снимается, можно CamelCase (`TeXGyreAdventor`, `TTMasters`); подпапки не читает. Корень — ещё не разобранное. `to-ttf` — woff/woff2 в корне текущей папки → ttf с тем же именем, веб-шрифт остаётся; CFF переводится в кривые TrueType; подпапки не читает.
Без PATH: относительный путь к `bin/to-mp4` или копия скрипта в рабочую папку (удалить после).
Сессии-подпапки в `inprogress/` — позже, если понадобится.

## Как писать код
- Bash (или zsh-совместимый), имена в `bin/`: **kebab-case**.
- Минимализм: только запрошенное; без лишних проверок и комментариев, если не просили.
- Утилиты под macOS; не ломать оба Mac без явного согласия.
- Медиа не складировать в репо как библиотеку (`.gitignore` уже режет типичные контейнеры).
- Общее — в `lib/`, когда реально понадобится дублирование.
