## Зачем
Bash-скрипты для медиа на macOS. Сюда только инструменты; готовые файлы — в библиотеки владельца.

Приоритет: **видео фильмов** (контейнер + дорожки, звук внутри файла). Чистый аудио и картинки — позже; не путать sound-in-video с отдельным mp3.

## Раскладка
| Путь          | Зачем                                              |
| ------------- | -------------------------------------------------- |
| `bin/`        | запускаемые скрипты (kebab-case: `to-mp4`, …)      |
| `lib/`        | общий код: `fixed-profile-queue.sh`, `fix-subs.py`, `to-txt.py`, `tag-movie.py` |
| `inprogress/` | временные медиа; после работы очищать              |
| `context/`    | `scripts.ai.txt` и ТЗ `context/<script>.txt`       |
| корень        | `README.md`, `.gitignore`                          |

Флоу: скрипты в `bin/` (не копировать в репо медиа). Видео — где угодно; часто `inprogress/`.
Запуск: PATH на `~/DEV/scripts/bin` в `~/.zshrc` → `cd` в папку с видео → `to-mp4` / `to-apple` / `to-lg-tv` / `cut-mp4` / `tag-movie` (см. [[README.md]]).
`to-apple` / `to-lg-tv` после подтверждения сами делают `caffeinate -is` (ночь без отдельной команды).
Скрипт смотрит только **текущую папку Терминала**; выход рядом с исходником → готовое в библиотеку → `inprogress/` очистить при необходимости.
`to-mp4` — общий конверт (mkv/… → mp4, ширина/CRF руками, H.264). `to-apple` — фикс-профиль под MacBook / iMac M1 / iPhone 14 Pro Max: mp4 + HEVC 1080p + AAC + mov_text. `to-lg-tv` — USB LG OLED65C24LA (C2): mkv + HEVC 1080p + AAC + SRT. `cut-mp4` — вырезка из **уже готового** mp4 (stream copy). `pack-show` — сезоны `s01` или `Show.S01`, серии `01. Название` или `Show.S01E01.Title…` → одна папка `S01E01 · Название.ext` (без названия серии — `S01E01.ext`; mv, предпросмотр). `sort-ready` — если есть и `_apple`, и `_lgc2`: в `Apple/` и `LG/` без суффикса, оригинал удалить; один конверт — не трогать. `clean-stick` — только на томе `/Volumes/…`: удалить `._*` и `.DS_Store`, затем повторная проверка.
`fix-subs` — готовый mp4/mkv: буквы-двойники в текстовых субтитрах по пометке rus/eng, видео и звук copy. То же вызывает очередь после успешного encode. `to-txt` — Word/DjVu → txt и docx для Pages; при запуске выбор меток сносок (stars/numbers/none), в файл пишутся номера; скан PDF не берёт. `tag-movie` — mp4 в текущей папке: по имени файла Кинопоиск предлагает русское и английское (`Пила 1 [Saw] 2004`), жанр подставляется из Википедии в тот же список, Enter оставляет. Постер 600×900: png в `~/Pictures/Video`, в mp4 — jpeg, MediaType Movie. Приложение TV подхватывает обложку при добавлении файла в библиотеку. exiftool, без перекода. Категорию в приложении TV владелец проверяет сам на файле, которого в библиотеке ещё не было. `tailwind-clr` — палитра Tailwind → `inprogress/tailwind.clr` (проверить → перенести); `--install` в `~/Library/Colors`.
Без PATH: относительный путь к `bin/to-mp4` или копия скрипта в рабочую папку (удалить после).
Сессии-подпапки в `inprogress/` — позже, если понадобится.

## Как писать код
- Bash (или zsh-совместимый), имена в `bin/`: **kebab-case**.
- Минимализм: только запрошенное; без лишних проверок и комментариев, если не просили.
- Утилиты под macOS; не ломать оба Mac без явного согласия.
- Медиа не складировать в репо как библиотеку (`.gitignore` уже режет типичные контейнеры).
- Общее — в `lib/`, когда реально понадобится дублирование.
