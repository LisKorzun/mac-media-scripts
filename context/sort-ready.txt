ТЗ — sort-ready

Назначение
  В одной папке лежат оригинал и уже готовые конверты to-apple / to-lg-tv.
  Если для названия есть оба конверта — разложить их по папкам и удалить оригинал.
  Если конверт только один — эту подборку не трогать.

Скрипт
  bin/sort-ready
  bash + python3
  UI как у pack-show.

Запуск
  cd в папку с файлами → sort-ready
  или cd в родителя → выбрать папку из списка.

Пара
  Ключ — имя без расширения и без суффикса.
  Apple: «Имя_apple.ext» (конец имени, не _apple_firstNm).
  LG: «Имя_lgc2.ext».
  Оригинал: «Имя.ext» (расширение может отличаться).
  Готово только если ровно один _apple и ровно один _lgc2.
  Ноль или один из них, или два файла одного типа — не трогать.

Действие
  Папки Apple/ и LG/ внутри той же папки.
  Apple/Имя.ext — суффикс _apple снят.
  LG/Имя.ext — суффикс _lgc2 снят.
  Оригинал удаляется только после обоих переносов.
  Если такое имя в папке уже есть — всю тройку пропустить.

Подтверждение
  Список переносов и список «оставлено».
  y / Y / Enter = да.

Не в этой версии
  Пробные _firstNm.
  to-mp4 (другой суффикс).
  Копирование вместо переноса.
