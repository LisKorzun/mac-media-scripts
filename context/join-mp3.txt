ТЗ — join-mp3

Назначение
  Склеить соседние mp3 одного рассказа в один файл.
  Звук копируется, не пережимается.
  Куски удаляются. Номера файлов после них уменьшаются на (сколько склеили − 1).

Скрипт
  bin/join-mp3
  lib/join-mp3.py
  UI как у to-mp3: баннеры, цвета, ✓, вопросы по-английски.

Запуск
  cd в папку с mp3 → join-mp3
  Только mp3 в текущей папке. Подпапки не читает.
  Список идёт по номеру в начале имени. «02.mp3» — это номер 2, рядом с «01 - текст». Потом файлы без номера.

Выбор
  Номера слева в списке: 3-4, 3 4 5 или 14-18.
  Файлы идут подряд. Меньше двух нельзя.

Имя
  Общее название без номера части.
  03 1910 - Ходынка 01 и 02 → 03 1910 - Ходынка.mp3.
  Хвост «День 1», «Часть 1», «Глава 1» тоже снимается.
  Номер части перед скобками снимается, чтец остаётся: Крестник 1 [Илья Бобылев] → Крестник [Илья Бобылев].
  Enter оставляет предложенное. Можно вписать своё.
  В теге Title — это название, без номера части. Остальные теги берутся из первого файла.

Звук
  Кодек, частота и число каналов должны совпадать, иначе стоп и файлы на месте.
  Число кадров звука сверяется с суммой кусков. Несколько кадров на стыке допустимы. Не хватает куска — файлы остаются.

Номера
  Новый файл получает номер первого куска.
  У файлов после блока номер уменьшается. «04.mp3» тоже сдвигается, не только «04 - текст».
  Файл без номера в начале имени не переименовывается.
