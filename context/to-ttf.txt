ТЗ — to-ttf

Назначение
  В текущей папке лежат веб-шрифты woff или woff2.
  Рядом записать ttf с тем же именем.
  Веб-шрифт не удалять.
  Подпапки не читать: человек сам заходит в папку одного семейства.

Скрипт
  bin/to-ttf
  lib/to-ttf.py
  bash + python3 + fonttools + brotli
  UI как у sort-fonts.

Запуск
  cd в папку семейства → to-ttf.
  Нет woff/woff2 в корне этой папки — отказ и подсказка зайти в папку шрифта.
  Нет пакетов: «pip3 install fonttools brotli».

Имя
  Poppins-Bold.woff2 → Poppins-Bold.ttf
  Уже есть такой ttf — этот веб-шрифт пропустить.
  И woff, и woff2 с одним именем — брать woff2.

Конверт
  woff2/woff с кривыми TrueType: снять сжатие, записать ttf.
  Внутри кривые PostScript (CFF): перевести в кривые TrueType и записать ttf.
  Подпись файла — TrueType, не OTTO.

Подтверждение
  Список новых ttf и список пропусков.
  y / Y / Enter = да.
  Повторный запуск, когда ttf уже лежат, ничего не пишет.

Не в этой версии
  Обход всех папок библиотеки.
  Удаление woff/woff2 после конверта.
  Переменные шрифты.
